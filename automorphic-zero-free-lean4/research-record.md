# Research record

The two-sided width is written as 1/(C log |T|) in unitary normalization. Each high-ordinate assertion applies to an individual fixed representation or curve.

| Method | Result and scope |
| --- | --- |
| Positive mixtures of real-abscissa Poisson kernels | The sharp fixed-abscissa positive subtraction is computed in `Research/Stechkin.lean`. Its conductor multiplier has a limiting value larger than one half. |
| Finite alternating real shifts | The full-strip comparison stays nonnegative and the multiplier tends to one half. Exact target retention permits an explicit conductor-eleven calculation. |
| Euler positivity, a local disk and an unsigned average | A quartic autocorrelation converts central-line exponents into an edge exclusion. A degree-twenty table gives 6.16918, with a full 222-rectangle formal certificate. |
| Optimizing an ordinary test profile | The compact cosine has a closed integral identity. A larger class of positive-definite, nonnegative windows includes a rationally certified spline giving 6.168704. See `notes/spline-section.tex` and `verification/spline.txt`. |
| An exponential tilt | Apply the signed average to the difference between two exact Hadamard identities. Combining it with an ordinary disk inequality preserves the central growth exponent. Formal components include a signed Fubini theorem for real zero kernels, the individual Laplace transform and a twice-integrated far-zero bound. |
| Restricting the moving symmetric powers | A degree-twelve table uses only the original curve and its symmetric square at moving nonscalar indices. The rank-three prior then gives 5.8872. |
| Direct test for the symmetric square | The auxiliary octic has exactly one moving nonscalar coefficient. Its rational lower limit for the rescaled symmetric-square edge displacement exceeds 0.08478. Applying that prior to the degree-twelve table gives 5.7693. |
| Other fields and ranks | General-rank trace squares, fixed Hecke bounds, signed Brauer descent and Gram matrices for several ordinates give the separate theorems in the paper. The CM specialization follows from the classical Hecke factorization. |

The main coefficient measures the boundary of an asymptotically thin strip. An effective starting height is supplied for the separate conductor-eleven estimate. The central portions of the critical strips remain open over number fields.
